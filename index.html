Teoría: Modelos de Inventarios

Conceptos operativos, modelos determinísticos y su aplicación al inventario web del Cyber

Concepto Base

Definición de Inventario

El inventario es la acumulación de materiales tangibles necesarios para asegurar el flujo operativo del negocio. En nuestro **Cyber Papelería**, el inventario garantiza que no se detenga el servicio de impresiones (con existencias de resmas de papel y tóners) ni la venta de papelería general.

Aplicación Web: La tabla de existencias en pantalla muestra en tiempo real este concepto. Cada vez que se vende, el stock baja; cada vez que se compra, el stock sube y se recalcula el costo promedio ponderado.
EOQ

Modelos de Compra

Se aplican al adquirir productos listos para la venta a proveedores (ej. bolígrafos, carpetas o memorias USB):

  • Sin Escasez (EOQ Clásico): Las compras ingresan justo a tiempo cuando el inventario llega a cero. Es lo que usamos para productos clave como **Resmas de Papel A4** para no rechazar clientes.
  • Con Escasez Diferida: Se permiten compras atrasadas cuando el cliente acepta pagar y esperar. Se aplica en artículos costosos (ej. **Audífonos Gamer**) reduciendo el almacenamiento.
Aplicación Web: En el POS, si un producto tiene stock, se descuenta directamente (Compra sin Escasez). Si llega a cero, el sistema dispara una alerta visual de seguridad para evitar rupturas de stock.
POQ

Modelos de Manufacturación

Ocurre cuando el Cyber funciona como mini-productor de sus propios servicios:

  • Sin Escasez: Ensamblado a una tasa de producción $P$ superior a la demanda $D$. Se aplica al armar los **Combos Escolares** en el mostrador mientras la clientela los compra.
  • Con Escasez: Ocurre bajo pedido masivo (ej. anillado de **guías universitarias**). Se acumulan solicitudes en cola (escasez) que se completan progresivamente.
Aplicación Web: Refleja situaciones donde las existencias suben gradualmente mediante entradas de ensamble interno y se venden al por menor de forma controlada.
Gráfico Sawtooth

Gráfico Determinístico General (Dientes de Sierra)

Representa el nivel de stock en el tiempo. El inventario se abastece instantáneamente a un nivel máximo (cuando llega el pedido). Luego, disminuye de forma constante con una pendiente de debida a las ventas diarias.

Para evitar retrasos del proveedor, el pedido se emite cuando el stock alcanza el Punto de Reorden (R), calculado en base al Lead Time (Lt) (tiempo de entrega del proveedor).
